# การทดสอบระบบ (Accuracy & Latency)

สคริปต์ชุดนี้ใช้หาตัวเลขสำหรับบทที่ 4 ของรายงาน และสร้างไฟล์ `evaluation.json` ให้หน้า "ผลการทดสอบ" บนเว็บ

## 1. เตรียมชุดทดสอบ (ทำครั้งเดียว)

```
backend/evaluation/
├── dataset/        ← ใส่ไฟล์ทรานสคริปต์ทดสอบ (.pdf .jpg .png) ตามสเปค 30 ไฟล์ ไทย+อังกฤษ
└── ground_truth/   ← เฉลย 1 ไฟล์ต่อ 1 เอกสาร ชื่อเดียวกัน แต่นามสกุล .json
```

ทำเฉลยได้ 2 วิธี

**วิธีที่ 1 (เร็ว)** อัปโหลดเอกสารทดสอบผ่านเว็บ ตรวจทานในหน้า Reviewer ให้ถูกทุกช่อง แล้วกดอนุมัติ จากนั้นรัน

```bash
cd backend
python evaluation/export_ground_truth.py
```

สคริปต์จะคัดลอกไฟล์ไป `dataset/` และสร้างเฉลยใน `ground_truth/` ให้ (เปิดเช็กกับเอกสารจริงอีกรอบ แล้วแก้ `_meta` ให้ถูกต้อง)

**วิธีที่ 2** เขียนเฉลยเองตามรูปแบบ `ground_truth_template.json`

ค่าใน `_meta`
- `language`: `th` หรือ `en` (ใช้แยกความแม่นยำตามภาษา)
- `source`: `native_pdf`, `scan` หรือ `photo`

## 2. รันการทดสอบ

```bash
cd backend
python evaluation/evaluate.py skew      # ทดสอบการแก้ภาพเอียง ±1–10 องศา (ไม่ใช้ API)
python evaluation/evaluate.py extract   # สกัดทุกไฟล์ด้วย Gemini + จับเวลา (ใช้ API, ไม่เขียนลงฐานข้อมูล)
python evaluation/evaluate.py score --name "ชุดทดสอบ KSU 30 ฉบับ"
```

หรือรันทีเดียว `python evaluation/evaluate.py all`

- `extract` ข้ามไฟล์ที่สกัดแล้ว ถ้าโควตา API หมดกลางทาง รันซ้ำได้เลย (ใช้ `--force` ถ้าต้องการสกัดใหม่ทั้งหมด)
- ถ้าโดน rate limit ให้เพิ่มเวลาพัก เช่น `--sleep 10`

## 3. ผลลัพธ์ (`evaluation/results/`)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `evaluation.json` | สรุปทั้งหมด (คัดลอกไป `frontend/public/evaluation.json` อัตโนมัติ) |
| `per_document.csv` | ผลรายเอกสาร (ใส่ภาคผนวก) |
| `skew_results.csv`, `skew_summary.json` | ผลทดสอบการแก้ภาพเอียง |
| `timings.json` | เวลาแต่ละขั้น (preprocess / extract / validate) ต่อเอกสาร |

## ตัวชี้วัดที่คำนวณ

- **ความแม่นยำรายฟิลด์** ส่วนหัว 9 ฟิลด์ และรายวิชา 5 ฟิลด์ (รหัส ชื่อไทย ชื่ออังกฤษ หน่วยกิต เกรด) เทียบแบบตรงตัวหลังตัดช่องว่าง ตัวเลขยอมคลาดเคลื่อน GPA ±0.005 หน่วยกิต ±0.05
- **Precision / Recall / F1 ของแถวรายวิชา** ระบบอ่านรายวิชาตกหล่น (FN) หรือเกินมา (FP) กี่แถว
- **ความแม่นยำรวม** = ช่องที่ถูก / ช่องทั้งหมด และแยกตามภาษา
- **ค่าความมั่นใจ** แถวที่ผิดถูกเตือน (< 0.85) กี่เปอร์เซ็นต์ และแถวที่ถูกเตือนผิดจริงกี่เปอร์เซ็นต์
- **เวลา** ต่อหน้าและต่อเอกสาร (เฉลี่ย มัธยฐาน p95) และเวลาเฉลี่ยของแต่ละขั้น
- **Deskew** มุมคงเหลือหลังแก้ และอัตราสำเร็จ (คงเหลือ ≤ 0.5°)
